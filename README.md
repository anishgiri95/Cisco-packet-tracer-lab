# Cisco-packet-tracer-lab
A hands-on series of 6 network design and security projects built in Cisco Packet Tracer — progressing from basic infrastructure to enterprise-grade VPN architecture.

|---|---------|--------|

## Skills being developed
- VLAN segmentation, trunking, inter-VLAN routing
- Network security hardening (SSH, Port Security, ACLs)
- Layer 2 redundancy (STP, EtherChannel)
- NAT/PAT, static routing, Zone-Based Firewall
- Monitoring infrastructure (Syslog, NTP, SNMP)
- IPsec VPN tunnel configuration and troubleshooting
